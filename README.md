# Clément Saillant

**Embedded Systems Engineer & AI Architect**

> *"I would rather be a cyborg than a goddess."* — Donna Haraway

I build hybrid organisms at the intersection of live performance technology, embedded systems, and artificial intelligence. Based in Beaujolais, France. My work fuses silicon and language — from ESP32 firmware to multi-machine LLM orchestration — because the most interesting things happen at the boundary between bodies and machines.

## Currently building

- **[Mascarade](https://github.com/electron-rare/mascarade)** — Multi-machine agentic LLM orchestration platform. P2P mesh, 8 providers, 29 fine-tuned models. *The nervous system.*
- **[Kill_LIFE](https://github.com/electron-rare/Kill_LIFE)** — Spec-first agentic methodology for embedded systems. ESP32/STM32, BMAD agents, evidence packs. *The skeleton.*
- **[KiC-AI](https://github.com/electron-rare/KiC-AI)** — AI-powered PCB design assistant for KiCad. Chat, analysis, local LLM. *The eye.*
- **[openDIAW.be](https://github.com/electron-rare/openDIAW.be)** — AI-powered music instruments for live performance. Drone, Grain, Glitch, KokoroTTS. *The voice.*
- **[Le Mystère du Professeur Zacus](https://github.com/electron-rare/le-mystere-professeur-zacus)** — AI-powered escape room. ESP32-S3 + React + voice pipeline. *The skin.*

> *"The body is not a biological given, but a techno-living political fiction."* — Paul B. Preciado

## Infrastructure & tools

- **[prima-cpp](https://github.com/electron-rare/prima-cpp)** — Distributed LLM inference with pipelined-ring parallelism (CUDA + ZMQ). C++.
- **[kill-life](https://github.com/electron-rare/kill-life)** — Kill_LIFE Python service — FastAPI + BMAD agents + MCP bridge to Mascarade.
- **[KiCAD-MCP-Server](https://github.com/electron-rare/KiCAD-MCP-Server)** — MCP implementation enabling LLMs (Claude, GPT) to directly interact with KiCad for PCB design.
- **[oidc2fer](https://github.com/electron-rare/oidc2fer)** — OIDC gateway to the French education federation (Renater). Go.

- **[ESP32_ZACUS](https://github.com/electron-rare/ESP32_ZACUS)** — Firmware ESP32 pour Le Mystère du Professeur Zacus. C.

- **[ESP32-P10-RGB-32x16-Digital-Clock](https://github.com/electron-rare/ESP32-P10-RGB-32x16-Digital-Clock)** — Horloge numérique ESP32 + panneaux LED P10 RGB + interface web.
- **[kxkm_clown](https://github.com/electron-rare/kxkm_clown)** — Multi-persona LLM chat system for live performance (KXKM).
